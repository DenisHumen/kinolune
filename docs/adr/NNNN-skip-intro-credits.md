# ADR-NNNN: Пропуск интро и титров — свой аудио-отпечаток на Rust, сверка по сезону, титры по картинке, сегменты в `pa-library`

- **Статус:** Предложен
- **Дата:** 2026-11-14
- **Решают:** владелец проекта (мейнтейнер); участники обсуждения — по PR
- **Связано:** PLAY-011, PLAY-005, PLAY-009, UI-013; `docs/research/01` §1.4 (Playback), §1.5; [ADR-0005](0005-license-mpl2-dco.md), [ADR-0034](0034-pa-probe-libavformat-runtime.md), [ADR-0048](0048-trickplay-previews.md), [ADR-0050](0050-player-osd.md)

## Контекст и проблема

Пропуск заставки и титров — функция паритета с Infuse (`docs/research/01` §1.4: «кнопка / авто через 3 с / мгновенно / выкл»). ADR-0050 оставил в OSD только хук `PlayRequest.skipSegments` и раннюю карточку Up Next на титрах; отрезки должен находить PLAY-011. Done when: на тестовом сезоне интро найдено в ≥ 90 % эпизодов с точностью ±2 с.

Образец — плагин Jellyfin intro-skipper: Chromaprint-отпечаток звука начала каждой серии, сверка серий сезона попарно со сдвигом, титры по чёрным кадрам. Chromaprint — LGPL-2.1 (C++). В Rust-крейты LGPL нельзя (ADR-0005, `cargo-deny`), а порт `rusty-chromaprint` тоже LGPL-2.1. Наш FFmpeg собран без `--enable-chromaprint`, а отдельная нативная библиотека Chromaprint означала бы ещё одну сборку на 7 платформ и ещё одну LGPL-библиотеку в рантайме.

## Факторы решения

- Только совместимые лицензии: без LGPL в Rust, без GPL в клиентах.
- Работает на всех платформах ядра без новых нативных библиотек.
- Точность ±2 с при разном холодном открытии (сдвиг интро) и разном кодировании серий.
- Фоновая работа без облака (ADR-0004), с источниками по сети (SMB, WebDAV) через `pa-vfs`.
- Новая серия сезона не должна заставлять заново читать остальные.

## Рассмотренные варианты

1. **Свой отпечаток на Rust** (схема Haitsma–Kalker 2002 г.), звук декодирует уже загруженный FFmpeg ядра.
2. Chromaprint, загружаемый в рантайме, как FFmpeg (`libloading`).
3. Крейт `rusty-chromaprint` (порт Chromaprint, LGPL-2.1).
4. Общественные базы IntroDB.app / TheIntroDB.org (как Infuse 8.4).

## Решение

Вариант **1**: отпечаток и сверка — наш код на Rust, без Chromaprint; FFmpeg только декодирует звук и кадры (LGPL, рантайм, ADR-0034). Вариант 2 возможен лицензионно, но требует отдельной сборки нативной библиотеки и не даёт выигрыша в точности на нашем тесте; вариант 3 запрещён политикой зависимостей; вариант 4 — внешний онлайн-сервис, его можно добавить позже как источник `import`.

- **Звук** — `pa-probe::AudioReader`: основная дорожка (по умолчанию, иначе первая), декодирование диапазона времени, сведение в моно в Rust для всех форматов сэмплов (без libswresample). Число каналов и частота берутся у декодера через AVOptions (`ch_layout`, `ar`), поэтому смена 2.0/5.1 посреди файла безопасна; из `AVFrame` читается только зеркальный префикс.
- **Отпечаток** (`pa-skip::fingerprint`): моно 8 кГц (ресемплер — окно-синк по таблице), кадры Ханна 256 мс с шагом 32 мс, БПФ, энергии 33 логарифмических полос 300–2000 Гц, бит `m` = знак изменения разности энергий полос `m` и `m+1` во времени. 32 бита на 32 мс; тишина (< −60 dBFS) — 0 и ни с чем не совпадает.
- **Сверка двух серий** (`matching`): голоса за сдвиг по совпадающим 16-битным половинам отпечатков (половина переживает перекодирование гораздо чаще, чем все 32 бита), для 8 сильнейших сдвигов — кадры с расстоянием Хэмминга ≤ 8 бит, сглаживание плотностью в окне 0,5 с, мосты через паузы до 1,5 с, обрезка по первому и последнему похожему кадру. Интро — от 15 с до 150 с; длиннее — это одна и та же серия дважды, не интро.
- **Сезон** (`season`): каждая серия сверяется с соседями (весь сезон до 13 серий, иначе по 6 с каждой стороны); кандидаты одной серии, совпадающие по началу (±3 с) и концу (±5 с), образуют кластер; побеждает самый большой, отрезок — медианы. Совпадение рекапа с прошлой серией так проигрывает интро. Окно поиска — первые 25 % файла, не больше 10 мин (как у intro-skipper).
- **Титры**: окно — последние 30 %, не больше 6 мин. По картинке (`credits`): ключевые кадры через `FrameGrabber` (как trickplay) каждую секунду, доля тёмных пикселей и «плотность текста» (яркие пиксели на резком краю); титры — последний длинный (≥ 15 с) отрезок чёрных кадров и светлого текста на тёмном, где текст есть хотя бы в 30 % кадров. Края уточняются бисекцией по точным кадрам: новый `FrameGrabber::grab_exact` декодирует от ключевого кадра до нужного времени; время кадра — `AVFrame.pts` по смещению для версии libavutil (поле `key_frame` удалено в libavutil 60; смещение 136 на 64-битных целях закреплено тестом), а при неправдоподобном времени уточнение отключается. По звуку — та же сверка сезона на окне титров (общая финальная песня). Если титры видны на картинке, начало берётся из картинки (песня часто начинается поверх последней сцены), конец — дальний из двух; иначе — из звука.
- **Главы** «Opening», «OP», «Intro», «Credits», «ED», «Ending», «Recap», «Preview» и русские («Заставка», «Титры»…) берутся как есть (`chapters`).
- **Хранение** — миграция `202611171200_PLAY-011_skip_segments` (только добавление): `skip_segments` (файл, вид, источник, начало, конец, уверенность; по одной строке на вид и источник) и `skip_analysis` (отпечатки окон интро и титров, титры по картинке, размер и mtime файла, версия анализа, ошибка). Воспроизведению отдаётся лучший источник каждого вида: `user` > `chapter` > `import` > `audio` > `video` (`pa_library::skip::effective_segments`). Новая серия сезона сверяется по сохранённым отпечаткам, остальные файлы не читаются; ошибка чтения повторяется не раньше чем через час.
- **Фоновая задача** — `pa_skip::analyze_season` (`JOB_KIND = "skip_segments"` для очереди сервера). В приложении — `CoreSkip` (`pa-frb`): `segments` отвечает из базы сразу, `analyze` ставит сезон файла в очередь одного фонового потока. Приложение ставит в очередь сезон серии, которую начинают смотреть; сезон — серии той же работы и номера сезона по сопоставлению, а для несопоставленных файлов — видеофайлы той же папки.
- **Плеер** — `PlayerScreen.skipMode` (`SkipMode.button | auto | instant | off`, настройка «Воспроизведение → Пропуск заставки и титров», по умолчанию кнопка). `auto` — кнопка с обратным отсчётом 3 с времени воспроизведения (на паузе отсчёт стоит), `instant` — сразу; автоматический пропуск — один раз на отрезок (вернулись назад — только кнопка). Пропуск титров, которые идут до конца файла, сразу включает следующую серию Up Next.

Замеры на сервере сборки — сгенерированный сезон (`core/crates/pa-skip/tools/make-test-season.py`): 8 серий по 8 мин с общим 40-секундным интро на сдвигах 0–60,7 с, общими титрами 50 с (белый текст на чёрном, общая финальная песня), сценой после титров в двух сериях, и спецвыпуск без интро и титров. Вариант `--hard` — разная громкость (−6…+2 дБ), свой шумовой фон −30 dBFS и разные кодеки (AAC 48 кГц, AAC 44,1 кГц, Opus).

| Сезон | Интро: точность / полнота | Макс. ошибка интро | Титры: точность / полнота | Макс. ошибка титров |
|---|---|---|---|---|
| обычный | 100 % / 100 % (8/8) | 96 мс | 100 % / 100 % (8/8) | 200 мс |
| `--hard` | 100 % / 100 % (8/8) | 156 мс | 100 % / 100 % (8/8) | 200 мс |
| `--hard`, титры только по звуку | — | — | 100 % / 100 % (8/8) | 221 мс |

Результаты одинаковы при допуске ±2 с и ±0,5 с; в спецвыпуске ничего не найдено. Анализ одной серии 640×360 с локального диска — около 1,2 с, сверка сезона — 0,04 с.

### Последствия

- Хорошо: done when PLAY-011 выполняется с запасом; нет новых нативных библиотек и лицензий, только наш код и уже загружаемый FFmpeg.
- Хорошо: сверка новой серии не перечитывает сезон; сегменты из глав, звука и картинки сосуществуют, и правка пользователя (`user`) их не стирает.
- Плохо: анализ читает начало (до 10 мин) и конец (до 6 мин) каждой серии целиком: для 1080p 8 Мбит/с по сети это около 1 ГБ на серию. Поэтому анализ запускается только для сезона, который смотрят, а не для всей медиатеки.
- Плохо: точность края титров по картинке зависит от бисекции по точным кадрам; если смещение `AVFrame.pts` не подходит (новый FFmpeg, 32-битная цель с другим выравниванием), остаётся точность ключевых кадров (GOP до 10 с).
- Плохо: титры поверх видеоряда (типично для аниме) по картинке не находятся — только по общей песне; рекап и превью — только по главам.
- Нейтрально: проверено на синтетическом сезоне; на реальных сериалах владельца — нет. Маркеры Plex и Jellyfin (импорт) и общественные базы интро не сделаны — отдельная задача PLAY-015.
