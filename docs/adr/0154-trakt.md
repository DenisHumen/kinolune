# ADR-0154: Trakt — вход кодом устройства, scrobble и двусторонняя синхронизация просмотренного

- **Статус:** Принят
- **Дата:** 2026-11-24
- **Решают:** мейнтейнер (владелец делегировал решения)
- **Связано:** SYNC-011, LEGAL-002 ([providers.md § Trakt](../legal/providers.md)), LIB-011 (прогресс), LIB-022 (оценки), SYNC-001/004 (ключи и операции синхронизации), NET-013/014 (отчёты Plex/Jellyfin), DEC-008 (ключи проекта при сборке)

## Контекст и проблема

Пользователи ведут историю просмотров в Trakt. Нужно: войти на любом устройстве, включая телевизор; отмечать в Trakt то, что играет плеер; перенести историю Trakt в «просмотрено» медиатеки и обратно; показать список «Хочу посмотреть»; связать наши оценки 1–5 со шкалой Trakt 1–10. Ограничения: приложение open source и работает без наших серверов; секретов в git нет; данные Trakt нельзя раздавать; лимит записей Trakt — 1 в секунду на пользователя.

## Решение

1. **Отдельный крейт `pa-trakt`** (блокирующий HTTP на `ureq`, как `pa-jellyfin`): клиент API v2, сессия с токенами, планы синхронизации. Сеть скрыта за трейтом `Transport`, тесты идут на записанных ответах (`testing::Recorded`), без живой сети. Медиатеку крейт не знает: синхронизация работает через трейт `sync::Library`, его реализует `pa-frb` поверх `pa-catalog`.
2. **Вход — device code flow** (`auth.trakt.tv/oauth/device/*`): код и QR-код страницы активации с подставленным кодом. Это рекомендованный Trakt путь для ТВ; production-приложения Trakt не принимают localhost и свои URL-схемы, поэтому PKCE с редиректом не подходит.
3. **Учётные данные.** `client_id` проекта встраивается при сборке из `PA_TRAKT_CLIENT_ID` / `CARGO_PA_TRAKT_CLIENT_ID` (как ключ TMDB, `release-app.yml`). `client_secret` Trakt пометил устаревшим и необязательным; он отправляется, только если задан (`PA_TRAKT_CLIENT_SECRET` или свой у пользователя). В open source клиенте он не секрет (как у десктопных клиентов Google) — в Secrets он лежит только чтобы не попасть в git. Пользователь может ввести свой Client ID и secret в расширенных настройках (сборки из исходников, F-Droid); они хранятся в `pa-secrets`.
4. **Токены** — в `pa-secrets` под ключом `trakt.tokens:main` (один аккаунт на устройство; имя пользователя только внутри секрета, ключ хранится открыто). Access token обновляется за сутки до истечения и один раз при `401`; одноразовый refresh token заменяется сразу; отказ обновления — выход.
5. **Scrobble** из пути прогресса плеера (`TraktScrobbler` рядом с `JellyfinReporter`): `start` при первом отчёте и после паузы, `pause` — если отчётов (раз в секунду, SYNC-014) нет 4 с, `stop` — при закрытии плеера или переходе к следующей серии. Название — по id: фильм по TMDB/IMDb/TVDB, серия — id сериала + сезон и номер (нумерация TMDB). `409` (только что отмечено) считается успехом. Просмотр Trakt засчитывает сам при `stop` ≥ 80 %.
6. **Пара «название Trakt ↔ элемент медиатеки» — по TMDB id** (ключи прогресса `tmdb:movie:`/`tmdb:episode:` уже есть, ADR-0079). Записи без TMDB id пропускаются.
7. **Просмотренное — две стороны, только рост.** Просмотр Trakt, которого нет здесь, отмечается «просмотрено» со временем Trakt — если название есть в медиатеке, ещё не просмотрено и здесь нет более нового состояния (позиция или «непросмотрено» позже времени Trakt выигрывает). Отметка идёт через реплику синхронизации, как любая. Просмотренное здесь, чего нет в Trakt, добавляется в историю Trakt с нашим временем пачками по 100. Повторный запуск ничего не меняет. «Непросмотрено» передаётся только явным действием меню (`/sync/history/remove`): по отсутствию записи нельзя отличить «удалили» от «ещё не синхронизировали».
8. **Оценки** (фильмы и сериалы): копируются туда, где их нет (Trakt = звёзды × 2, обратно — пополам с округлением вверх: 7 → 4); если различаются, побеждает более новая; 7/10 и 4 звезды считаются одинаковыми.
9. **Watchlist** читается в полку «Trakt: хочу посмотреть» на главной — только названия, которые есть в медиатеке; кэш 10 минут. Добавление и удаление — из меню фильма или сериала.
10. **Когда синхронизируется:** через 20 с после запуска, каждые 6 часов и по кнопке «Синхронизировать сейчас»; сразу после входа.
11. **Лимиты:** записи не чаще раза в 1,05 с (ждёт сам клиент); `429` с `Retry-After` ≤ 30 с — ждём и повторяем один раз, иначе ошибка `rate_limited`.

## Рассмотренные варианты

- **PKCE с редиректом на localhost.** Удобно на десктопе, но production-приложение Trakt не принимает localhost, и на ТВ не работает. Отклонено.
- **Импорт истории для всех названий, даже отсутствующих в медиатеке.** Тысячи строк прогресса и операций синхронизации ради файлов, которых нет. Отклонено: импорт только для того, что есть; при появлении файла следующий запуск синхронизации отметит его.
- **Перенос «непросмотрено» с Trakt по пропаже записи.** Нужен журнал синхронизированных ключей; ошибка стирает отметки. Отложено.
- **Свой сервер-посредник с секретом.** Противоречит принципу «без наших серверов» (ADR-0004). Отклонено.

## Последствия

- Хорошо: вход работает на ТВ; история и оценки сходятся без ручных действий; сборки без ключа проекта работают со своим Client ID.
- Плохо: серии с разной нумерацией в Trakt (TVDB) и TMDB могут не совпасть — такие пропускаются; удаление истории на Trakt не снимает отметку здесь.
- Нейтрально: оценки серий не синхронизируются (в медиатеке оценки у фильмов и сериалов).
- Владелец регистрирует приложение Trakt (нужен верифицированный GitHub-аккаунт; production-ревью; приложение, неактивное 30 дней, удаляется) и кладёт `PA_TRAKT_CLIENT_ID` (и при желании `PA_TRAKT_CLIENT_SECRET`) в Secrets окружений `release` и `store`.

## Как проверяем соблюдение

- `cargo test -p pa-trakt`: вход кодом (ожидание, «медленнее», подтверждение, без secret и с secret), обновление и ротация токенов, `401` → обновление, отказ обновления → выход, тела scrobble, `409` и `429`, синхронизация просмотренного и оценок в обе стороны и идемпотентность — на записанных ответах (`tests/recorded.rs`, `tests/fixtures/`).
- `cargo test -p pa-catalog --test external_titles`: id названий, отметка «просмотрено» со временем Trakt один раз, более новое местное состояние побеждает, оценки по названию.
- `flutter test test/trakt_test.dart`: start/pause/start/stop, Up Next, ничего без входа, периодическая синхронизация.
- Живой scrobble в тестовый аккаунт — вручную (каталог проверок, раздел Trakt).
