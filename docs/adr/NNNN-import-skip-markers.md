# ADR-NNNN: Импорт готовых маркеров интро и титров из Plex, Jellyfin и EDL; импорт важнее глав и распознавания

- **Статус:** Предложен
- **Дата:** 2026-11-14
- **Решают:** владелец проекта (мейнтейнер); участники обсуждения — по PR
- **Связано:** PLAY-015, PLAY-011, NET-012, LIB-007; `docs/research/01` §1.4 (Playback); [ADR-0058](0058-skip-intro-credits.md) (меняет порядок источников из раздела «Хранение»)

## Контекст и проблема

PLAY-011 (ADR-0058) находит интро и титры сам: по общему звуку серий сезона, по картинке и по именам глав. Но у многих пользователей отрезки уже размечены другой программой: Plex хранит маркеры `intro`/`credits` у эпизода, Jellyfin — Media Segments (10.10+) и плагин intro-skipper, а рядом с файлами лежат EDL (Kodi/MPlayer), которые пишут вручную, Comskip или тот же intro-skipper. Эта разметка точнее нашей догадки (её поставили или проверили для этого самого файла), и её не надо пересчитывать.

ADR-0058 ставил источник `import` ниже глав (`user` > `chapter` > `import` > `audio` > `video`). Done when PLAY-015: маркеры тестовых серверов Plex и Jellyfin попадают в `PlayRequest.skipSegments` с точностью ±0,5 с.

## Факторы решения

- Всё локально (ADR-0004): никаких облачных баз и наших серверов; ходить к Plex и Jellyfin по сети — задача клиента серверов (NET-012), не этой.
- Явная разметка для конкретного файла надёжнее имени главы («Chapter 2» с интро внутри, глава «OP» на 3 мин вместе с холодным открытием) и тем более отпечатка.
- Правка пользователя (`user`) по-прежнему главнее всего.
- Сетевой источник может быть недоступен: пропавший сервер не должен стирать уже импортированное.
- Без новых лицензий: JSON и XML разбираются уже используемыми `serde_json` и `quick-xml`.

## Рассмотренные варианты

1. **Разбор форматов в `pa-skip` + сайдкары рядом с видео + приём ответа сервера через API**; импорт выше глав.
2. То же, но импорт ниже глав (как в ADR-0058).
3. Сразу ходить к Plex/Jellyfin по сети за маркерами.
4. Читать базу Plex (`com.plexapp.plugins.library.db`) или XML-хранилище intro-skipper напрямую.

## Решение

Вариант **1**.

- **Форматы** (`pa_skip::import`):
  - **EDL** (`<stem>.edl`) — строки `начало конец действие`; время в секундах (`12.5`) или `[чч:]мм:сс[.ддд]`; кадры (`#123`) пропускаются (нужна частота кадров). Пропуском считаются действия 0 (вырезать), 2 (метка сцены с концом) и 3 (рекламная пауза); 1 (заглушить) — нет; без действия — вырезать (как в Kodi). EDL не говорит, что это за отрезок, поэтому: **интро** — первый отрезок, который начинается в первой четверти файла и в первые 10 мин и длится не больше 5 мин; **титры** — последний, который начинается во второй половине, кончается не раньше чем за 10 мин до конца и длится не больше 15 мин (нужна длительность файла: из `files.duration_ms`, иначе из анализа PLAY-011). Отрезки посередине (рекламные паузы Comskip) не берутся.
  - **Plex** — ответ `/library/metadata/<id>?includeMarkers=1` в JSON (`MediaContainer.Metadata[].Marker[]`) или XML (`<Marker type startTimeOffset endTimeOffset>`), смещения в мс; `intro` → интро, `credits` → титры, `commercial` пропускается. Ответ с маркерами нескольких элементов отклоняется — это не маркеры одного файла.
  - **Jellyfin** — ответ Media Segments API (`Items[]` с `Type`, `StartTicks`, `EndTicks`; тики по 100 нс; `Intro`, `Outro` → титры, `Recap`, `Preview`; `Commercial` и `Unknown` пропускаются; сегменты нескольких `ItemId` отклоняются) или плагина intro-skipper (`IntroStart`/`IntroEnd` в секундах, отдельно или по режимам `{"Introduction": …, "Credits": …}`; `Valid: false` — нет отрезка).
- **Откуда берутся.** Сайдкары рядом с видео: `<stem>.edl`, а сохранённые ответы серверов — `<stem>.plex.json`, `<stem>.plex.xml`, `<stem>.jellyfin.json` (имя без учёта регистра). Фоновая очередь `CoreSkip` перед анализом сезона вызывает `pa_skip::import_season`: один листинг папки на сезон (новый метод `Opener::list`), чтение сайдкаров до 1 МиБ. Ответ сервера, полученный приложением (NET-012), передаётся в `CoreSkip.importMarkers(sourceId, relPath, provider, payload)` → `pa_skip::import_markers`. Сами запросы к серверам Plex и Jellyfin здесь не делаются.
- **Один импортированный отрезок на вид.** Среди сайдкаров одного файла типизированные экспорты (Plex, затем Jellyfin) важнее догадки EDL; сайдкар важнее ответа, переданного программой (файл положил пользователь). Пересканирование сайдкаров заменяет только строки, которые записало само (`provider_ref` не NULL): удалённый сайдкар уносит свои маркеры, переданные через API остаются. Если папку не удалось прочитать или сайдкар не открылся (источник недоступен), импорт файла не меняется.
- **Хранение** — миграция `202611171500_PLAY-015_skip_import_provider` (только добавление): в `skip_segments` колонки `provider` (`plex` | `jellyfin` | `edl`) и `provider_ref` (имя сайдкара или NULL). Источник `import` и ограничение «одна строка на файл, вид и источник» — из ADR-0058.
- **Порядок источников** (`pa_library::skip::effective_segments`, порядок `SkipOrigin`): **`user` > `import` > `chapter` > `audio` > `video`**. Это меняет ADR-0058, где `import` стоял ниже глав.
- **Для интерфейса** — `CoreSkipSegment` и Dart `MediaSkipSegment` отдают `origin` и, для импорта, `provider` и `providerFile`: плеер может показать «Пропустить интро (Plex)».

Не входит: запросы к Plex и Jellyfin (NET-012); общественные базы IntroDB/TheIntroDB; запись своих отрезков обратно в EDL; импорт для фильмов, которым приложение не ставит анализ (сейчас очередь ставится для серий).

### Последствия

- Хорошо: маркеры Plex и Jellyfin переносятся без потерь (мс и тики, ±0 мс на тестовых данных, допуск done when — ±0,5 с); интро и титры есть сразу, до долгого анализа звука.
- Хорошо: сайдкары — обычные файлы рядом с видео; формат открытый, их легко сохранить руками (`curl … > Episode.plex.json`) или из скрипта.
- Плохо: вид отрезка EDL угадывается по положению; рекламная пауза в первые минуты записи ТВ (Comskip) станет «интро». Типизированный экспорт рядом с тем же файлом это перекрывает.
- Плохо: если в сайдкаре ошибка (сдвиг после перекодирования), импорт перекрывает верное распознавание; исправить можно правкой `user` или удалением сайдкара.
- Нейтрально: анализ PLAY-011 идёт и для файлов с импортом (нужен для соседних серий сезона); пропускать его — возможная оптимизация.
- Нейтрально: сопоставить элемент Plex/Jellyfin с файлом медиатеки (по пути или id) — задача NET-012; ей остаётся вызвать `importMarkers` с ответом сервера.
