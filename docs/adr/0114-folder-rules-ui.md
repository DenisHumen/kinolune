# ADR-0114: «Тип и нумерация» в «Исправить распознавание»: нумерация свёрнута в одну строку, тип — сразу, «Забыть правило папки» — без подтверждения

- **Статус:** Предложен
- **Дата:** 2026-11-18
- **Решают:** владелец проекта (мейнтейнер); участники обсуждения — по PR
- **Связано:** META-035 (эта задача), META-017 ([ADR-0112](0112-folder-rules-release-templates.md)), META-016 ([ADR-0101](0101-review-inbox.md)), META-034, META-015 ([ADR-0085](0085-episode-numbering-module.md))

## Контекст и проблема

Ядро META-017 уже умеет задавать работе нумерацию (`set_numbering`: сезон, сдвиг, абсолютный счёт) и тип (`set_work_kind`) на всю папку и забывать правило папки (`forget_folder_rules`), но в приложении этих действий нет: пользователь может только подтвердить или выбрать другой результат. Нужно показать их на странице «Исправить распознавание» (она же страница работы в инбоксе «На проверку») так, чтобы обычному пользователю ничего не приходилось трогать, пока серии на своих местах, и чтобы всё работало с пульта ТВ.

## Факторы решения

- Максимально просто для пользователя: разумные значения по умолчанию, ни одного обязательного поля.
- Понятно без справки: правило читается как фраза «Серия в имени + N = серия сезона S».
- Без новых экранов: та же страница, общий дизайн, редизайн позже (DSN).
- ТВ: всё доступно стрелками и «ОК», поля ввода не ловят фокус.

## Рассмотренные варианты

1. Отдельный экран «Правила папок» в настройках со списком всех правил.
2. **Раздел «Тип и нумерация» на странице «Исправить распознавание»; нумерация свёрнута в строку с текущим правилом и кнопкой «Изменить нумерацию».**
3. Поля «сезон / сдвиг / абсолютный» всегда открыты на странице.

## Решение

Выбран вариант **2**: вариант 1 — лишний экран и лишнее понятие для пользователя (правило появляется само из исправления, ADR-0112), вариант 3 перегружает страницу полями, которые почти никогда не нужны.

**Тип.** Три кнопки-выбора «Фильм / Сериал / Аниме», выбран текущий тип работы (новый вызов ядра `work_kind`, FRB `folder_rules` возвращает его вместе с правилами). Нажатие сразу применяет тип ко всей папке (`set_work_kind`) и закрывает страницу: между фильмом и сериалом работа ищется заново, старые кандидаты на странице уже неверны. Подтверждения нет: тип можно переключить обратно тем же нажатием.

**Нумерация** — только у сериала и аниме. По умолчанию одна строка с текущим правилом словами («Серии как в именах файлов» или «Серия в имени − 28 = серия сезона 2») и кнопка «Изменить нумерацию». Редактор — фраза «Серия в имени + [N] = серия сезона [S]»: поля с кнопками «−» и «+», начальные значения — из текущего правила папки (так «Верно» после META-015 сразу показывает выученный сдвиг), иначе `N = 0` и пустой сезон. Пустой сезон — «как в имени» (`season = None` ядра), это значение по умолчанию; «−» на сезоне 0 возвращает к «как в имени». Переключатель «Сквозная нумерация (абсолютный номер)» убирает сезон и меняет фразу на «= абсолютный номер». Под полями — пример «Например: серия 13 в имени → сезон 2, серия 1», пересчитывается при каждом изменении. «Применить» активна, только если значения отличаются от текущих; после применения страница остаётся открытой (виден результат и строка правила), прогон метаданных запускается сразу.

**Правило папки.** Если у работы есть правила — строка «Новые файлы папки «Anime/Frieren» следуют этому исправлению» (папка относительно источника, без полного пути; для корня источника — «Новые файлы этого источника…») и кнопка «Забыть правило папки». Подтверждения нет: принятые решения по файлам остаются, ничего не удаляется, правило появится снова при следующем исправлении (ADR-0112).

**ТВ.** Все элементы — `KFocusable`/`KButton` в одной `FocusTraversalGroup`; у числовых полей стрелки вверх и вниз уводят фокус из поля (`DirectionalFocusIntent(ignoreTextFields: false)`), влево и вправо двигают курсор; «−» и «+» позволяют менять числа без экранной клавиатуры.

**Ошибка** ядра (например, «у работы нет своей папки для правила») показывается под разделом, редактор остаётся открытым.

**API.** FRB `pa-frb/src/api/folder_rules.rs`: `folder_rules(item_id) -> CoreFolderRules { kind, rules }`, `set_numbering(item_id, season, offset, absolute)`, `set_work_kind(item_id, kind)`, `forget_folder_rules(item_id) -> u32`; в Dart — методы `ReviewInbox` (`folderRules`, `setNumbering`, `setKind`, `forgetFolderRules`) и модели `FolderRules`, `FolderRule`. Ядро: добавлен только `Catalog::work_kind`; схема БД не меняется.

### Последствия

- Хорошо: пользователь, у которого всё распознано верно, видит одну строку и ничего не трогает; исправление нумерации — одно действие на всю папку, включая будущие серии.
- Хорошо: работает с пульта без экранной клавиатуры.
- Плохо: списка всех правил папок нет; правило видно и забывается только со страницы работы.
- Нейтрально: шаблоны релиза (ADR-0112) не показываются — это внутренняя деталь распознавания.

### Как проверяем соблюдение

`clients/flutter/app/test/folder_rules_test.dart`: свёрнутая нумерация, редактор и пример, сезон «как в имени», абсолютный счёт, отмена, «Забыть правило папки», тип закрывает страницу, у фильма нет нумерации, стрелки уходят из полей, ошибка остаётся на странице. `clients/flutter/packages/pa_library/test/review_inbox_test.dart` — те же вызовы через мост на настоящем ядре; `core/crates/pa-catalog/tests/folder_rules.rs` — `work_kind`.
