# ADR-NNNN: веб-интерфейс `alpha-admin` — статические файлы без сборки, токены и палитры из генератора

- **Статус:** Предложен
- **Дата:** 2026-11-26
- **Решают:** мейнтейнер (владелец делегировал решения)
- **Связано:** DIST-014, DIST-013, DIST-018, DIST-009, DSN-003, DSN-017, SRV-014; [ADR-0165](0165-alpha-admin-backend.md), [ADR-0164](0164-alpha-updated-agent.md); [палитра v2](../design/palette-v2.md); [исследование 05](../research/05-nas-linux-distro.md) §5.1

## Контекст и проблема

`alpha-admin` (DIST-013) отдавал заглушку на `/`. Нужен веб-интерфейс: вход, дашборд, сеть, пользователи, обновления с откатом, «Расширенный режим (Cockpit)». Ограничения: всё работает в LAN без интернета (никаких CDN), CSP демона `default-src 'self'` (нет inline-скриптов и стилей), образ ОС собирается в CI без npm, цвета — только из дизайн-токенов, палитра должна меняться одним файлом (палитра v2, № 12 «Бордо и графит»). Страницы пользователей, Samba и SSH даёт DIST-018 (ещё не влит), интерфейс должен работать и с ним, и без него.

## Рассмотренные варианты

1. SPA на Svelte или Preact со сборкой (рекомендация SRV-014 для админки медиасервера).
2. Серверный рендеринг шаблонами Go (`html/template`) с формами.
3. Статические HTML, CSS и ES-модули без сборки, встроенные в бинарник через `go:embed`; данные — только из документированного REST API.

## Решение

- **Вариант 3.** Около десятка экранов, у каждого — пара запросов к API; фреймворк и сборщик (npm, lock-файл, транспиляция) добавили бы цепочку поставки в образ ОС ради мелкой экономии кода. Браузеры с ES2020-модулями есть везде, где открывают админку. Интерфейс ходит только в `/api/v1/…` — тот же API, что у клиентского приложения, поэтому всё, что умеет UI, умеет и приложение. Шаблоны Go (вариант 2) потребовали бы второго слоя обработчиков рядом с API. SRV-014 решит свой стек отдельно; общими остаются токены (`tokens.css`) и визуальный язык.
- **Файлы:** `distro/admin/internal/webui/static/` (`index.html`, `app.css`, `js/*.js`, `tokens.css`, `i18n/*.json`), пакет `webui` отдаёт их с `Cache-Control: no-cache` и ETag по содержимому; маршрут `GET /` и `GET /static/…` в `server.go`. `tokens.css` — копия `design/tokens/generated/web/tokens.css`: `go:embed` не выходит за модуль, а тест `TestTokensUpToDate` падает, если копия отстала.
- **Цвета — только семантические токены** (`--pa-bg-*`, `--pa-text-*`, `--pa-accent-*`, `--pa-border-*`, `--pa-status-*`, `--pa-glass-*`). Литерал цвета в `app.css` ловит тест `TestNoColorLiterals`.
- **Палитры — слой генератора токенов.** `design/tokens/palettes/<имя>.tokens.json` переопределяет семантические цвета поверх тёмной темы (шесть базовых цветов палитры v2 и выведенные из них роли); CSS-эмиттер добавляет блок `[data-palette="<имя>"]`, валидатор проверяет контраст каждой палитры по тем же парам, что и темы. Админка ставит `data-palette="bordeaux-graphite"`; сменить палитру — поменять атрибут или файл палитры. Dart, Swift и Kotlin палитры пока не получают — это часть DSN-017.
- **Жидкое стекло:** панели — `--pa-glass-*-tint` + `backdrop-filter: blur() saturate()`, кромка и блик; без размытия (`@supports not (backdrop-filter…)`, `prefers-reduced-transparency`) — непрозрачный `--pa-glass-*-fallback`. Фоновые пятна из акцентов двигаются медленно и выключаются при `prefers-reduced-motion`.
- **Возможности по API:** UI читает `/api/v1/openapi.yaml` и показывает разделы «Пользователи», «Общие папки» и «SSH», только если в нём есть их пути (DIST-018). Пока DIST-018 не влит, этих разделов просто нет.
- **Обновления:** «Проверить», «Скачать», «Установить сейчас» (с подтверждением и предупреждением о перезагрузке) или «в окно обслуживания», «Откатить» (с перезагрузкой), канал, авто-режим и окно — всё через `/api/v1/system/update…`. Release notes — ссылка на GitHub Releases: у агента обновлений нет поля с текстом изменений; появится — покажем внутри.
- **Cockpit** — только кнопка «Расширенный режим»: открывает/закрывает проём `cockpit` firewalld через API и ссылку `https://<хост>:9090`. Сама админка доступна только из LAN (ADR-0165), поэтому и кнопка видна только там.
- **Языки:** ru (по умолчанию), en, uk — JSON-словари; выбор по `install.language`, затем по языку браузера, переключатель в шапке.

## Последствия

- Нет сборки и npm в образе; правка UI — правка файла и `go test`.
- Палитры появились в генераторе раньше DSN-017: DSN-017 расширит их на Flutter, Apple и Android, формат файла уже задан.
- Управление обновлениями ОС из клиентского приложения через медиасервер — отдельная часть DIST-014 (сервер + Flutter), в этот ADR не входит.
