# ADR-0100: Трейлеры в баннере карточки и просмотренность на кадрах

- **Статус:** Принят
- **Дата:** 2026-11-17
- **Решают:** владелец проекта (поведение), мейнтейнер (источники и детали)
- **Связано:** UI-036, UI-037, DSN-019, DSN-021, LIB-011, LIB-013, UI-010

## Контекст и проблема

Владелец (2026-11-17):
- в карточке фильма или сериала вверху играет трейлер как видео-баннер; кнопкой «вверх» на пульте он открывается на весь экран;
- на кадре серии просмотренная часть резкая, а остальное размыто, с разделением и значком;
- для непросмотренных серий и для фильмов вид продумать самим;
- откуда брать трейлеры — решить самим.

## Решение

### Источники трейлеров

Порядок такой:
1. Свой файл рядом с фильмом.
2. Трейлер с медиасервера пользователя.
3. TMDB `videos` — ролики YouTube и Vimeo.

Ролики YouTube играем только официальным встроенным плеером (IFrame API, домен `youtube-nocookie.com`) во WebView. Ни скачивания, ни извлечения потока (yt-dlp и подобного) нет: это нарушает условия YouTube, а для открытого проекта это риск блокировки и претензий. Плеер получает только ID ролика из TMDB. Пока карточка не открыта, запросов к YouTube нет. Интернет-трейлеры можно выключить в настройках: проект локальный, внешние запросы — по согласию пользователя.

На tvOS WebView нет. Там играем свой файл или трейлер с сервера, иначе открываем приложение YouTube по ссылке. Если трейлера нет совсем, вместо видео идёт медленный «живой» фон из backdrop.

### Поведение

- Автопревью в баннере начинается без звука примерно через 1,5 с после открытия карточки.
- На телевизоре фокус стоит на «Смотреть». «Вверх» открывает трейлер на весь экран со звуком, «Назад» возвращает в карточку на прежнее место.
- Автопревью ставится на паузу, когда карточка вне экрана, при энергосбережении и на мобильной сети (по настройке), а при системном «уменьшить движение» не запускается совсем.

### Просмотренность

- **Серии и кадры 16:9:**
  - начато — резкая доля слева, размытая и затемнённая справа, черта на границе, значок «◐» и «ещё N мин»;
  - просмотрено — кадр приглушён, значок «✓»;
  - не смотрели — чистый кадр с акцентной точкой;
  - следующая серия — подпись «Далее»;
  - с Hide Spoilers кадры будущих серий размыты целиком.
- **Постеры 2:3** не размываются, потому что на них название. Начатый фильм — полоса прогресса снизу и значок; у сериала — счётчик непросмотренных серий или «✓».
- Разделение «резко/размыто» для фильма показываем на его кадре 16:9: в «Продолжить» и в карточке.
- Размытие не единственный признак: у полосы и времени есть текстовая семантика для скринридера.
- Размытая копия считается один раз на уменьшенной картинке и кэшируется, без живого blur на телевизоре.

## Последствия

- WebView-плеер — новая зависимость на Android, Windows, macOS и Linux. Её лицензия проверяется в `cargo deny` и `reuse`; GPL не допускается.
- DSN-019 из глобального редизайна теперь только оформляет то, что делает UI-036.
