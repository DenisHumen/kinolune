# ADR-NNNN: Сетевая папка SMB выбирается на сервере, а не вводится по имени общей папки

- **Статус:** Предложен
- **Дата:** 2026-11-15
- **Решают:** мейнтейнер (владелец делегировал решения по интерфейсу)
- **Связано:** `UI-028`, `NET-002`, `NET-003`, `NET-011`, `NET-020`, `LIB-018`; [ADR-0033](0033-libsmb2-runtime-loading.md), [ADR-0038](0038-network-playback-loopback-proxy.md)

## Контекст и проблема

В alpha.7 владелец добавлял папку с домашнего Linux-сервера с Samba. Файлы лежат в
`/home/<user>/smb_shared/torrents/downloads`. В форме он ввёл «Общая папка» = `home` и «Папка
внутри» = `<user>/smb_shared/torrents/downloads` — так путь выглядит на диске сервера. Получил
«Папка не найдена… диск отключён». На самом деле на сервере нет общей папки `home`: Samba отдаёт
домашние каталоги как общую папку с именем пользователя (`[homes]`), а `smb_shared` может быть
отдельной общей папкой. Человек думает путями на диске и не знает, что такое общая папка (share).
Сообщение об ошибке было неверным: `STATUS_BAD_NETWORK_NAME` при подключении классифицировался как
обычный «не найден путь».

## Решение

1. **Выбор вместо ввода.** Добавление SMB — мастер из трёх шагов: сервер (найденный в сети по
   NET-020 или любой вставленный адрес: `192.168.1.10`, `\\nas\share\dir`, `smb://…`,
   `nas/share/dir`, путь как на диске), вход (имя и пароль или «без пароля», проверка сразу),
   выбор папки (список общих папок сервера, затем вложенные папки и кнопка «Использовать эту
   папку»). Имя общей папки пользователь не вводит. Дополнительные параметры (домен, версия SMB,
   шифрование, подпись) свёрнуты.
2. **Список общих папок — через libsmb2** (`smb2_share_enum_async`, srvsvc `NetShareEnum`
   уровня 1 по `IPC$`; есть в закреплённой 6.3.2). Синхронной обёртки в libsmb2 нет, поэтому
   `pa-smb2` крутит цикл событий сам: `smb2_get_fd`/`smb2_which_events`/`poll(2)`/`smb2_service`
   с тайм-аутом контекста; на Windows вместо `poll` — короткий сон (сокет неблокирующий,
   `WSAEWOULDBLOCK` libsmb2 считает «пока нечего»). Ответ, который libsmb2 ещё может заполнить
   (тайм-аут, ошибка), живёт до уничтожения контекста. Скрываются принтеры, `IPC$` и все имена на
   `$` (`C$`, `ADMIN$`, `print$`). Пять новых функций добавлены в список обязательных символов
   `tools/libsmb2/lib/smb2.sh`.
3. **Автоподбор введённого пути** (`pa_sources::smb_find`). Путь делится на папки; проверяются,
   подключением и `stat`: путь как введён; общая папка с именем каждой папки пути (это покрывает
   `[homes]` — общая папка с именем пользователя — и общую папку, указывающую вглубь домашнего
   каталога); для `home/…`, `homes/…`, `Users/…` без имени пользователя — домашняя общая папка
   пользователя. Имена, которых нет в списке сервера, не пробуются (кроме имени пользователя: его
   домашняя папка часто скрыта). Места, ведущие в один и тот же каталог (одинаковый ненулевой
   идентификатор файла сервера, у Samba — inode), схлопываются в самое конкретное. Одно место —
   открывается сразу с пояснением «Нашли: общая папка «…», внутри …»; несколько — пользователь
   выбирает; ни одного — список общих папок.
4. **Ошибки по-человечески.** Подключение к несуществующей общей папке теперь несёт в сообщении
   метку `share not found` (`pa_vfs_smb::SHARE_NOT_FOUND`) и в приложении становится отдельным
   кодом `shareNotFound`: «На сервере нет общей папки с таким именем. Нажмите «Выбрать папку»…».
   Мастер различает: сервер не отвечает, неверное имя или пароль, сервер не пускает гостей, нет
   такой общей папки, нет папки внутри, нет доступа.
5. **Вход без пароля.** Анонимный вход, при отказе — анонимный по SMB 2, затем `guest` с пустым
   паролем по SMB 2. Гостевая сессия не может подписывать, а SMB 3.1.1 требует подписи, поэтому
   Samba с `map to guest = bad user` отказывает гостю по SMB 3 (проверено в Docker). Это же
   правило работает при сканировании и воспроизведении сохранённого «гостевого» источника.
6. **Исправление существующего источника.** В форме изменения SMB вместо полей «Общая папка» и
   «Папка внутри» — строка «Папка на сервере» и кнопка «Выбрать папку» (поля по имени остались под
   «Дополнительно»). У источника с ошибкой «нет общей папки» или «нет папки» на карточке появляется
   «Выбрать папку». Обзор открывается с сохранённым паролем (`SourceManager::smb_login_of`,
   пароль в Dart не возвращается) и сразу там, где ядро нашло сохранённый путь.

## Последствия

- Владельцу с неправильным источником из alpha.7 достаточно «Проверить связь» → «Выбрать папку» →
  «Использовать эту папку».
- Обзор есть у ядра (`CoreSourceManager`); резервный менеджер без ядра показывает прежнюю форму.
- Новые FRB-вызовы: `CoreSources::smb_shares`, `smb_list_folder`, `smb_find`.
- Не сделано: такой же обзор до сохранения для SFTP/FTP/WebDAV (там адрес уже вводится одним
  полем, и обзор работает после добавления через «Обзор файлов»).
- Перебор кандидатов подключается к серверу до 8 раз; на домашней сети это доли секунды.
