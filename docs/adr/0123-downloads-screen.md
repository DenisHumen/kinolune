# ADR-0123: Экран «Загрузки» — прогресс по шине событий ядра, автоочистка включена по умолчанию, вход из навигации

- **Статус:** Предложен
- **Дата:** 2026-11-18
- **Решают:** владелец проекта (поручил решать по правилу «максимально просто для клиента»), мейнтейнер
- **Связано:** UI-018, UI-002, CORE-009, CORE-011, CORE-012, NET-019; [ADR-0067](0067-offline-copies.md), [ADR-0121](0121-core-event-bus-error-codes.md), [ADR-0062](0062-storage-targets-retention.md); `docs/research/01` §2.6

## Контекст и проблема

NET-019 (ADR-0067) сделал офлайн-копии и простой экран «Загрузки»: список, кнопки строки, блок настроек. Прогресс шёл из собственного потока `CoreOffline.watch`, экран открывался только из Настроек, «удалять просмотренное» по умолчанию было выключено, а места на диске было видно одной строкой в настройках. UI-018 требует полноценный экран: очередь `pa-jobs` с прогрессом, паузой и отменой, офлайн-копии, занятое место и автоочистку; «done when» — widget-тесты и прогресс по событиям. CORE-009 (ADR-0121) дал единый поток `core_events`.

## Решение

- **Прогресс — из `core_events`.** `CoreOfflineBackend.changes()` подписывается на шину ядра; чистая функция `offlineChangeOf(CoreEvent)` переводит `jobChanged` в изменение списка: `progress` → байты строки на месте (без перечитывания списка), `stateChanged` и `added` задач вида `offline_copy` → состояние строки сразу и перечитывание через 150 мс (детали: копия, причина ожидания), `removed` → перечитывание, если задача наша. События задач других видов (загрузки и запись Twitch в той же очереди) и других доменов игнорируются; события `progress` и `removed` без вида — по `job_id` из списка. `CoreOffline.watch` в ядре остаётся (ADR-0121: старые потоки не ломаем), приложение им больше не пользуется. Фильтр по `library_path` не нужен: у приложения одна база.
- **Экран.** Разделы «Очередь» (незавершённые, с ошибкой и отменённые; «Приостановить все» / «Продолжить все») и «Офлайн-копии» (число и размер); карточка «Место» — одна полоса «Загрузки · Другие файлы · Свободно» и предупреждение «Мало места», когда свободно меньше 2 ГБ или 5 % тома (ниже этого `pa-storage` всё равно держит резерв и задачи ждут); строка текущего правила автоочистки и кнопка «Удалить просмотренное (N)» с подтверждением. Настройки (папка, Wi-Fi only, «удалять просмотренное») — тот же блок, что в Настройках.
- **Раскладки.** Уже 900 логических пикселей — одна колонка (телефон, узкое окно); шире — список слева, «Место» и настройки справа (компьютер, планшет, ТВ). На ТВ фокус пульта при открытии — на «Приостановить все» или на первой кнопке строки; кнопки строк — `KFocusable` с белой заливкой в фокусе вместо `IconButton`.
- **Вход.** Пункт «Загрузки» внизу боковой панели и узкой панели (над прогрессом скана) и значок рядом с профилем на «Главной» телефона — только пока есть загрузки или копии, с числом загрузок и общим процентом. Отдельного раздела навигации нет: у большинства пользователей загрузок нет, лишний раздел мешал бы. На ТВ экран открывается из Настроек (на tvOS загрузок нет вовсе).
- **Автоочистка по умолчанию — «через 7 дней».** При первом запуске версии с UI-018, если правило «удалять просмотренное» не задано и загрузок на устройстве ещё нет, приложение ставит 7 дней и запоминает это (`offline_cleanup_default`); дальше выбор пользователя не трогается. Избранное ядро не удаляет (ADR-0067). 7 дней — компромисс: копия не пропадает сразу после просмотра (можно пересмотреть), но место на телефоне освобождается без участия человека. Новых настроек не добавлено.

## Последствия

- Хорошо: прогресс приходит из той же шины, что и у остальных экранов; одна подписка, без опроса; Twitch-задачи в общей очереди не вызывают лишних перечитываний.
- Хорошо: загрузки видны из основной навигации, место и автоочистка — на одном экране, без захода в настройки.
- Плохо: до UI-018 «не задано» и «Не удалять» в ядре не различались, поэтому на устройствах, где копии уже есть, правило по умолчанию не ставится вовсе (чтобы не удалить копии того, кто сам выбрал «Не удалять»); такие пользователи включают автоочистку сами в карточке «Место».
- Ограничение: «Приостановить все» и «Удалить просмотренное» — цикл вызовов по одной задаче/копии (в ядре нет пакетного вызова); на сотнях загрузок это заметно, для типичных десятков — нет.
- Ограничение: «просмотрено» для кнопки «Удалить просмотренное» берётся из списка ядра (`sync_watched` при очистке, ADR-0067) — копия, досмотренная только что, получит отметку при следующей очистке (открытие экрана).

## Как проверяем соблюдение

`flutter test test/downloads_screen_test.dart`: перевод событий ядра (`offlineChangeOf`), прогресс и состояние строки по событиям без перечитывания списка, игнор задач Twitch, «Приостановить все» / «Продолжить все», полоса места и «Мало места», автоочистка по умолчанию один раз и «Удалить просмотренное», раскладки телефона и компьютера, фокус пульта на ТВ, вход из боковой панели и с «Главной» телефона; скриншоты — `docs/screenshots/progress/ui-018/`. `test/offline_test.dart` (NET-019) проходит без изменений.
