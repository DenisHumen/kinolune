# Чек-лист: passthrough звука на Android (PLAY-AND-004)

Строки каталога — PLAY-170…174 и SET-160 ([test-catalog.md](test-catalog.md)), решение — ADR-NNNN. Займёт 20–30 минут.

## Что нужно

- Nvidia Shield (или Chromecast with Google TV) → AV-ресивер или саундбар с Dolby Atmos по HDMI/eARC; ресивер должен показывать формат (дисплей или меню на экране).
- Телефон или приставка без passthrough (встроенные динамики, телевизор без ARC).
- Файлы MKV с дорожками: Dolby TrueHD + Atmos, E-AC-3 + Atmos, AC-3 5.1, DTS 5.1, DTS-HD MA 7.1 (можно один файл с пятью дорожками).
- В системных настройках приставки: «Звук → Объёмный звук → Авто» (на Shield: «Audio → Surround sound → Auto», Dolby Atmos — вкл.).

## Порядок

1. **Авто, Shield + ресивер (PLAY-170).** Настройки → Воспроизведение → «Звук: Авто (passthrough)». Открыть файл, включить статистику в плеере. По очереди переключать дорожки:
   - TrueHD + Atmos → ресивер «Dolby Atmos» / «TrueHD Atmos»; в статистике «Путь звука: Без декодирования (passthrough)».
   - E-AC-3 + Atmos → «Dolby Atmos» (DD+); AC-3 → «Dolby Digital»; DTS → «DTS»; DTS-HD MA → «DTS-HD MA».
   - Записать, если ресивер молчит или щёлкает при переключении дорожки — это не норма.
2. **Всегда декодировать (PLAY-172, SET-160).** Переключить на «Всегда декодировать», открыть видео заново → ресивер «PCM» / «Multi Ch PCM» на всех дорожках, статистика «Декодируется в PCM». Вернуть «Авто».
3. **Устройство без passthrough (PLAY-171).** На телефоне (или приставке без ресивера) открыть тот же файл: каждая дорожка звучит (стерео на динамиках), статистика «Декодируется в PCM», нет тишины и ошибки «формат не поддерживается».
4. **Ресивер без части форматов (PLAY-173), если есть такой саундбар.** DTS на саундбаре только с Dolby → звук есть (PCM). DTS-HD MA на ресивере только с DTS → «DTS» (ядро 5.1).
5. **Плеер Media3 (PLAY-174), когда есть сборка с `pa_player_android` и FFmpeg-расширением** (`just android ffmpeg-ext arm64-v8a`, `-PpaFfmpegExtDir=…`): шаги 1–3 в нём; на телефоне TrueHD и DTS-HD должны звучать (декодирует FFmpeg).

## Что прислать

Для каждой строки: устройство, модель ресивера, что показал ресивер, строку «Путь звука» из статистики (скриншот), и `adb logcat -d | grep -i -E "audiotrack|spdif|passthrough|ffmpeg"` при проблеме.
