## Не подтвердилось (не баги)

- «После перезапуска пропал прогресс и „Продолжить“» и «серия после „Далее“ остаётся на 92 %» — артефакт медиатеки с одинаковыми файлами: Kinolune отождествляет файлы по содержимому (OSHash), и прогресс «перетекал» между фильмами и сериями. На `--unique` прогресс после перезапуска сохраняется («Продолжить с 0:13»), серия после «Далее» засчитывается.
- «Перемотка за конец замирает на последнем кадре» — на `--unique` перемотка за конец и ровно в конец переходит к «Далее»/следующей серии. В прогоне 1 кадр стоял (С1·Э4) — возможно, тоже из-за одинаковых файлов; перепроверить на длинных настоящих файлах.

## Что работает (проверено)

Первый запуск и онбординг (3 шага), обнаружение SMB-серверов в сети (3 сервера), добавление локальной папки по пути, сканирование (53 файла за ~5 с), распознавание TMDB (рус. названия, постеры), главная, «Продолжить просмотр», страница фильма и сериала, воспроизведение (часы идут в реальном времени), пауза, перемотка ±10 с и стрелками, «закончится в …», позиция сохраняется («Продолжить с 0:59»), «Далее» и автопереход к следующей серии, «Пропустить заставку», поиск по русскому и оригинальному названию, музыка (альбом, «Слушать», переход трек→трек, пауза), отслеживание папки (новый файл в медиатеке через ~2 с, распознан ещё через ~1 с), «На проверку» с причинами, «Состояние и журнал», экспорт отчёта без личных данных, перезапуск с сохранением состояния. На профиле пользователя alpha.19 показывает SMB-медиатеку (49 сериалов, 29 фильмов) — исправление BUG-018 работает.

## Урок для скрипта и процедуры

- Медиатеку для прогонов генерировать с `--unique` (добавлено в `tools/qa/media/library.py`).
- Flutter строит дерево доступности только для построенных элементов: в ленивых списках (полки главной) карточки за краем не видны даже в `tree -All` — к ним надо прокручивать.
- Клик мышью иногда не доходит (окно не стало активным) — тогда `act` (действие MSAA по умолчанию).
- Кликать после `wait`: клик в момент перестройки страницы попадает в другую кнопку.
- Git Bash переписывает аргументы, начинающиеся с `/`: вызывать с `MSYS_NO_PATHCONV=1` или из PowerShell.
