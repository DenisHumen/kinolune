# Profiles, PIN and parental controls

Each profile has its own watch progress, Continue Watching, favorites, search history, music queue, smart playlists and track preferences. The library and sources are shared.

## Create a profile

Settings → Profiles → Manage profiles → "Add profile" or "Add kid profile".

- "Name", "Colour", "Picture" (the first letter of the name or a picture).
- "Set PIN" — 4 to 8 digits. A profile with a PIN opens only after the PIN is entered.
- "Save". "Delete profile" removes the profile together with its progress (you cannot delete the current or the only profile).

## Switch profiles

Settings → Profiles → Switch profile. Turn on "Ask who is watching at start" to get the "Who is watching?" screen on every start.

## Parental controls

The **parent PIN** is the PIN of any profile without restrictions. Give your own profile a PIN before creating a kid profile.

"Add kid profile" turns on safe settings right away; you can change them:

- "Age limit" — for example up to 12+; older movies are hidden. "Rating country" — whose ratings to use ("Strictest" by default).
- "Hide unrated video" — home and unrecognised videos.
- "Hide artwork".
- Hide Streams.
- "Only chosen folders" — the profile sees only the content of the chosen folders ("Add folder").

Leaving a kid profile, or opening Settings in it, needs the parent PIN. A child picks their own profile without a PIN.

Settings → Profiles also has:

- **App Lock** — a PIN at start and when you come back to the app;
- **Search Lock** — Search opens only after the parent PIN.

After several wrong PINs, input is blocked for a while.

Profiles and their PINs are shared with paired devices (the PIN itself is never sent — only a protected fingerprint of it). On Android TV, App Lock or a profile PIN empties the Kinolune row in the launcher.
