# Руководство пользователя Kinolune / Kinolune user guide

Kinolune — свободный медиаплеер для фильмов, сериалов, музыки и аудиокниг. Он работает только на ваших устройствах: аккаунта, облака и серверов проекта нет.

Kinolune is a free media player for movies, shows, music and audiobooks. It runs only on your devices: there is no account, no cloud and no project servers.
