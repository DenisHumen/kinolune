# Установка и обновления

Kinolune скачивается со страницы [GitHub Releases](https://github.com/DenisHumen/kinolune/releases). Выберите самый новый релиз и в блоке «Assets» скачайте файл для своего устройства:

| Устройство | Файл |
|---|---|
| Windows 10 и 11 (64 бита) | `kinolune-<версия>-windows-x64-setup.exe` — установщик (рекомендуем) или `…-windows-x64.zip` — портативная копия |
| Mac с Apple silicon (M1 и новее) | `kinolune-<версия>-macos-arm64.dmg` |
| Mac с процессором Intel | `kinolune-<версия>-macos-x86_64.dmg` |
| Linux (x86_64) | `kinolune-<версия>-x86_64.AppImage` (рекомендуем) или `…-linux-x86_64.tar.gz` |
| Android-телефон, планшет, Android TV, Google TV | `kinolune-<версия>-android-universal.apk` — подходит всем. Если знаете процессор: `arm64-v8a` (почти все современные), `armeabi-v7a` (старые и недорогие ТВ-приставки), `x86_64` (эмуляторы) |

Сборок для iPhone, iPad и Apple TV пока нет.

Сборки с GitHub — «полные» (full): в них есть обновление из приложения, загрузки и запись Twitch. Сборки из магазинов приложений (когда появятся) обновляет сам магазин.

## Windows

1. Запустите `kinolune-<версия>-windows-x64-setup.exe`. Права администратора не нужны: Kinolune ставится только для вашего пользователя, ярлыки появляются в меню «Пуск» и на рабочем столе.
2. Сборка пока не подписана сертификатом, поэтому Windows может показать «Система Windows защитила ваш компьютер». Нажмите **«Подробнее» → «Выполнить в любом случае»**. Это нужно один раз для каждой скачанной версии.
3. При первом поиске сетевых папок Windows спросит про брандмауэр — разрешите Kinolune доступ к **частным** сетям, иначе компьютеры и NAS в домашней сети не найдутся.

Удалить: «Параметры → Приложения → Kinolune → Удалить». Медиатека и настройки при этом остаются; пароли сетевых папок хранятся в диспетчере учётных данных Windows.

**Портативная копия (zip).** Распакуйте архив целиком в любую папку, где вам можно писать (например, «Документы\Kinolune»), и запустите `Kinolune.exe`. Не переносите exe отдельно от остальных файлов. Портативная копия сама не обновляется: приложение покажет, что вышла новая версия, а распаковать её нужно самим.

## macOS

Нужна macOS 12 или новее.

1. Откройте скачанный `.dmg` и перетащите **Kinolune.app** на папку **Applications** (Программы) в том же окне.
2. Приложение пока не заверено Apple, поэтому первый запуск macOS блокирует («Не удаётся открыть Kinolune» или «Apple не может проверить…»). Разрешите его **один раз** любым способом:
   - **Без Терминала:** в Finder нажмите на Kinolune.app правой кнопкой (или с Control) → **«Открыть»** → снова **«Открыть»**. На macOS 15 и новее, если кнопки «Открыть» нет: «Системные настройки → Конфиденциальность и безопасность» → внизу у сообщения о Kinolune **«Всё равно открыть»**.
   - **В Терминале** (Программы → Утилиты → Терминал) вставьте команду и нажмите Return:

     ```bash
     xattr -dr com.apple.quarantine /Applications/Kinolune.app
     ```

3. Запустите Kinolune из папки «Программы». macOS может спросить, можно ли искать устройства в локальной сети и открывать папки вроде «Загрузки» или «Документы», — разрешите, иначе не будут работать сетевые папки, медиасерверы и синхронизация.

Если вы ставите новую версию поверх вручную из DMG, шаг 2 понадобится снова. Обновление из самого приложения (ниже) делает всё само.

## Linux

Нужен дистрибутив с glibc 2.39 или новее (например, Ubuntu 24.04+, Fedora 40+), GTK 3 и PipeWire или PulseAudio. Видеодвижок (libmpv и FFmpeg) уже внутри.

1. Сделайте файл исполняемым: в свойствах файла отметьте «Разрешить запуск как программы» или выполните

   ```bash
   chmod +x kinolune-*-x86_64.AppImage
   ```

2. Запустите AppImage двойным щелчком или из терминала.

Если AppImage не запускается с сообщением про FUSE, установите пакет `libfuse2` (в Ubuntu 24.04 — `libfuse2t64`) или используйте архив `tar.gz`: распакуйте его и запустите `./kinolune`.

Ссылки `kinolune://` и пункт «Открыть с помощью → Kinolune» появляются, когда AppImage встроен в меню (например, через Gear Lever или AppImageLauncher).

## Android, Android TV и Google TV

1. Скачайте APK на устройство (на ТВ удобно через приложение-загрузчик или флешку).
2. Откройте файл. Android попросит разрешить установку из этого источника (браузера или файлового менеджера) — разрешите и вернитесь назад.
3. Нажмите «Установить».

На Android TV и Google TV приложение появляется в лаунчере с баннером Kinolune и сразу работает с пульта.

Если Android пишет, что приложение «не установлено», а Kinolune уже стоит, — старая версия подписана другим ключом (так было у самых первых альф). Удалите старую версию и поставьте новую. Медиатека при этом сканируется заново.

## Первый запуск

При первом запуске открывается мастер из пяти шагов: язык, «Как вы будете смотреть?» (сейчас доступно «Только приложение»), имя и цвет профиля, первый источник и сопряжение с другими устройствами. Любой шаг можно пропустить кнопкой «Пропустить». Кнопка «Открыть демо-медиатеку» показывает приложение на вымышленных фильмах, ничего не сохраняя.

Мастер можно открыть снова: «Настройки → О программе → Мастер первого запуска».

## Обновления

**Как узнать, что вышла новая версия.** Сверху приложения появляется полоса «Доступна версия X» с кнопками «Что нового», «Скачать» и «Позже». То же видно в «Настройки → О программе → Обновления» (там же кнопка «Проверить обновления»).

**Как обновиться.**

| Где установлено | Что происходит |
|---|---|
| Windows (установщик), macOS, Linux AppImage | Обновление скачивается и проверяется в фоне. Когда готово — нажмите «Перезапустить». На Windows обновление ставится и просто при выходе из приложения. Посреди фильма Kinolune сам не перезапускается |
| Android | «Скачать» → системный установщик → «Обновить». Если Android попросит, разрешите Kinolune устанавливать приложения («Разрешить установку», затем «Попробовать ещё раз») |
| Windows zip, Linux tar.gz, пакеты .deb/.rpm, Flatpak, Snap | Приложение только сообщает о новой версии; «Скачать» открывает нужный файл в браузере |

Каждый скачанный файл проверяется по подписи релиза. Если файл повреждён или подменён, Kinolune его удаляет и ничего не ставит.

**Настройки** («Настройки → О программе → Обновления»):

- «Проверять обновления автоматически» — через 5 секунд после запуска и раз в 6 часов. Выключите, если хотите проверять только кнопкой.
- «Когда выходит новая версия»: «Обновлять автоматически» (по умолчанию) или «Только сообщать».
- «Канал обновлений»: «Стабильные релизы» или «Включая пре-релизы (альфа, бета)». Пока у вас стоит альфа или бета, по умолчанию выбраны пре-релизы, так что менять ничего не нужно.

Медиатека, прогресс просмотра и настройки при обновлении сохраняются.
