# Профили, PIN и родительский контроль

У каждого профиля свои прогресс просмотра, «Продолжить просмотр», избранное, история поиска, очередь музыки, умные плейлисты и настройки дорожек. Медиатека и источники общие.

## Создать профиль

«Настройки → Профили → Управление профилями» → «Добавить профиль» или «Добавить детский профиль».

- «Имя», «Цвет», «Картинка» (первая буква имени или картинка).
- «Задать PIN» — от 4 до 8 цифр. Профиль с PIN открывается только после ввода PIN.
- «Сохранить». «Удалить профиль» удаляет профиль вместе с его прогрессом (текущий и единственный профиль удалить нельзя).

## Сменить профиль

«Настройки → Профили → Сменить профиль». Включите «Спрашивать при запуске, кто смотрит», чтобы при каждом запуске появлялся экран «Кто смотрит?».

## Родительский контроль

**PIN родителя** — PIN любого профиля без ограничений. Задайте его своему профилю до того, как создавать детский.

«Добавить детский профиль» сразу включает безопасные настройки; их можно поменять:

- «Ограничение по возрасту» — например «До 12+»; фильмы старше скрыты. «Страна рейтинга» — по какой стране считать рейтинг («Самый строгий» по умолчанию).
- «Скрывать видео без рейтинга» — домашнее и нераспознанное видео.
- «Скрывать обложки».
- «Скрывать «Стримы»».
- «Только выбранные папки» — профиль видит только содержимое выбранных папок («Добавить папку»).

Чтобы выйти из детского профиля или открыть в нём «Настройки», нужен PIN родителя. Ребёнок выбирает свой профиль без PIN.

«Настройки → Профили» также:

- **«Блокировка приложения»** — PIN при запуске и при возвращении в приложение;
- **«Блокировка поиска»** — «Поиск» открывается только после PIN родителя.

После нескольких неверных PIN ввод блокируется на время («Повторите через м:сс»).

Профили и их PIN передаются на сопряжённые устройства (сам PIN не передаётся — только его защищённый отпечаток). На Android TV при блокировке приложения или PIN профиля ряд Kinolune в лаунчере пустеет.
