# Twitch

Раздел «Стримы» показывает эфиры и записи каналов Twitch. Kinolune не связан с Twitch; каналы, записи и эфиры берутся с Twitch.

## Включить

«Настройки → Стримы Twitch → Показывать Twitch». После этого в меню появятся «Стримы». У детских профилей и профилей с ограничениями раздел по умолчанию скрыт.

## Без входа и со входом

Без входа можно добавить каналы в «Избранное» по имени: вкладка «Поиск» → введите имя → «Добавить канал <имя>».

Вход нужен, чтобы видеть, кто сейчас в эфире, новые записи, отслеживаемые каналы и писать в чат:

1. «Войти через Twitch».
2. На телефоне откройте `twitch.tv/activate` (или отсканируйте QR-код) и введите показанный код.
3. Окно закроется само. Пароль Twitch Kinolune не видит — хранится только ключ доступа.

Выйти: нажмите на свой аккаунт в шапке → «Выйти из Twitch».

## Что есть в разделе

- **«Главная»**: «Сейчас в эфире», «Избранное» (каналы можно закрепить сверху), «Продолжить просмотр», «Новые записи», «Скоро в эфире», «Категории ваших стримеров».
- **«Каналы»**: избранное и отслеживаемые, фильтр «В эфире» / «Не в эфире», сортировка.
- **«Поиск»**: каналы и категории.
- **Страница канала**: «Смотреть эфир», «Избранное», «Уведомления вкл./выкл.», «Открыть чат», вкладки «Записи», «Хайлайты», «Клипы», «Расписание», «О канале».

Записи «Только для подписчиков» и клипы открываются на сайте Twitch: Kinolune показывает ссылку и QR-код.

## Плеер

- **Сборки с GitHub (full)** играют эфиры и записи в плеере Kinolune: низкая задержка, «К эфиру», выбор «Качество» и «Только звук», главы и скорость у записей, чат сбоку или поверх видео (режим «театр»). Реклама Twitch показывается как есть и не блокируется.
- **Сборки из магазинов** (когда появятся) используют официальный плеер Twitch, а где его нет — ссылку «Открыть на Twitch».

Если плеер не запустился, есть «Повторить» и «Открыть в плеере Twitch».

## Чат

Чат читается без входа. Чтобы писать, войдите (нужно право на чат). В «Настройках чата» можно скрыть ботов, подсвечивать своё имя и слова, заблокировать пользователей и добавить фильтр слов. «Остановить анимированные эмоуты» — в шапке чата или в «Настройки → Стримы Twitch». На ТВ чат только для чтения.

## Уведомления об эфирах

Если вы вошли, включите «Уведомления вкл.» на странице канала из избранного — придёт системное уведомление «<канал> в эфире». На Android приложение спросит разрешение на уведомления; при закрытом приложении проверка идёт в фоне не чаще раза в 15 минут. На Windows таких уведомлений пока нет.

## Загрузки и запись эфиров (только full)

- **«Скачать»** в плеере записи — скачать запись целиком или главу. Список — «Загрузки».
- **«Запись»** на странице канала — правило автозаписи эфиров: качество, «Записывать чат», сколько эфиров или дней хранить, категории. При первом включении Kinolune напомнит: записи — только для личного использования, условия Twitch не разрешают распространять или перезаливать их.
- **«Записи и загрузки»** — сохранённые файлы; «Импорт» добавляет файлы, скачанные другими программами.
- «Настройки → Стримы Twitch → Записи и загрузки» — папки, квота места и шаблоны имён файлов.

Запись идёт, пока Kinolune запущен. У детского профиля записей и загрузок не видно.
