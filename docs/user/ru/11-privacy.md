# Конфиденциальность и внешние сервисы

У Kinolune нет аккаунтов, серверов и телеметрии. Медиатека, прогресс, пароли и настройки хранятся только на ваших устройствах. Полный текст — [политика конфиденциальности](../../legal/privacy-policy.md).

## Свой медиасервер Kinolune

Если вы запускаете медиасервер Kinolune (`alpha-media`), он доступен только в домашней сети: устройства с адресами вашего роутера (192.168.x.x, 10.x.x.x и т. п.) подключаются, а соединения из интернета сервер сбрасывает, даже если на роутере проброшен порт. Сам сервер порты на роутере не открывает (UPnP нет). Пускать только этот компьютер — `clients = "local"` в конфиге; пускать всех, включая интернет, — `clients = "any"`. Последнее опасно: делайте так, только если понимаете, зачем, например за своим VPN.

Пока на сервере не создан администратор, управлять им можно только с самого компьютера с сервером или по одноразовому коду из файла `setup-code.txt` в его папке данных.

## Где хранятся пароли

Пароли сетевых папок, ключи медиасерверов, вход в Twitch и OpenSubtitles хранятся в защищённом хранилище системы: Keychain (macOS), Android Keystore, диспетчер учётных данных Windows, Secret Service (Linux). Если на Linux такого хранилища нет, Kinolune хранит их в зашифрованном файле и один раз предупреждает об этом. Где именно — видно в «Настройки → Конфиденциальность → Где хранятся пароли».

## К каким сервисам обращается приложение

Запросы идут напрямую с вашего устройства. Сервис видит ваш IP-адрес и сам запрос, но не ваши файлы.

| Сервис | Зачем | Как выключить |
|---|---|---|
| TMDB | Названия, постеры, описания фильмов и сериалов | Не выключается: без него фильмы не распознаются. Можно указать свой ключ («Настройки → Метаданные») |
| AniList, Shikimori | Распознавание аниме | — |
| GitHub | Обновление базы аниме (раз в сутки), подписанного конфига приложения и проверка новых версий Kinolune | «Настройки → Метаданные → Обновлять базу аниме»; «Настройки → О программе → Обновления → Проверять обновления автоматически» |
| MusicBrainz, Cover Art Archive | Сведения о музыке и обложки | — |
| Open Library | Описания и обложки аудиокниг | — |
| YouTube, Vimeo | Трейлеры на странице фильма, когда своего трейлера нет; только когда вы открыли страницу | «Настройки → Трейлеры → Трейлеры из интернета» |
| OpenSubtitles | Поиск субтитров — только когда вы нажали «Найти субтитры» | Просто не пользоваться поиском |
| SubDL | Поиск субтитров — только когда вы нажали «Найти субтитры»; уходят ID фильма или сериала (IMDb/TMDB), сезон и серия, языки, а без ID — название и год | Просто не пользоваться поиском |
| trace.moe | Распознавание аниме по кадрам | **Выключено по умолчанию**; включается в «Настройки → Метаданные → Распознавать аниме по кадрам» |
| Twitch, 7TV, BTTV, FFZ | Раздел «Стримы» и эмоуты чата | Раздел выключен по умолчанию: «Настройки → Стримы Twitch → Показывать Twitch» |

Ваши сетевые источники (NAS, Jellyfin, Emby, Subsonic) и синхронизация между устройствами работают только между вашими устройствами.

## Что ещё можно сделать

- «Настройки → Конфиденциальность → Очистить историю поиска».
- «Настройки → Хранилище → Очистить кэш картинок».
- «Настройки → Диагностика → Сохранять логи и отчёты о сбоях» — выключите, и логи удалятся. Логи никуда не отправляются (см. [«Если что-то не работает»](12-troubleshooting.md)).
- Личные видео держите в [«Личном»](05-personal-and-files.md) под PIN или паролем.
