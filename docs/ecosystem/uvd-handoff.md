# Universal Video Downloader → сервер Kinolune: что сделать в UVD (ECO-007)

> Передаётся в репозиторий [Universal-Video-Downloader](https://github.com/DenisHumen/Universal-Video-Downloader). **Работа начинается только по команде владельца** — до этого схема лежит как план. Общая схема — [`README.md`](README.md); протокол и API со стороны сервера появятся в задачах ECO-001…ECO-005 Kinolune, UVD их только использует.

## Что должно появиться в UVD

1. **Поиск сервера.** Фоновое прослушивание mDNS/DNS-SD службы `_kinolune._tcp` в локальной сети; список найденных серверов (имя, адрес) в Настройках → «Сервер Kinolune»; ввод адреса вручную, если mDNS не работает.
2. **Подключение один раз.** Выбрал сервер → UVD показывает временный код и QR (одноразовые, 5 минут) → подтверждение на сервере (QR из Kinolune на телефоне, код в админке) **или** вход логином и паролем пользователя сервера. После успеха — сохранённая сессия (токен в системном хранилище ключей: Keychain / Credential Manager / Secret Service), переподключение не нужно; после 14 дней без активности (настройка сервера) — снова код или пароль. Проверка TLS-сертификата по отпечатку из mDNS/QR.
3. **«Отправить на сервер».** Кнопка у готовой загрузки и в меню очереди; настройка «отправлять всё автоматически» и отдельно для «Новых серий» (вместо или вместе с копированием на сетевую папку, которое уже есть); загрузка по частям с продолжением после обрыва, прогресс в очереди; описание файла: ссылка-источник, сайт, тип (фильм / серия / стрим), название, сезон и серия (из того, что UVD уже знает для «Новых серий»), канал и дата для Twitch, хэш.
4. **Статусы с сервера.** Подписка на события сервера: «На сервере», «Просмотрено», «Удалено с сервера» у отправленных файлов; при ошибке (нет места, нет прав, сессия истекла) — понятное сообщение и что сделать.
5. **Удаление.** «Удалить с сервера» у отправленного файла (право `delete:own`); если удалили на сервере — у файла в UVD метка, файл на компьютере не трогается без отдельного действия.
6. **Без сервера всё как раньше.** Сервер — необязательное дополнение: ни аккаунта, ни облака, ни телеметрии.

## Порядок

UVD начинает после того, как на стороне Kinolune готовы протокол и API (ECO-001…ECO-005) — до этого можно только спроектировать интерфейс. Проверка — общий e2e: UVD скачивает тестовое видео → отправляет на тестовый сервер → оно появляется в Kinolune → удаление в Kinolune → UVD показывает «Удалено с сервера».
