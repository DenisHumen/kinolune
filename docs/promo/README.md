# Продвижение Kinolune

План продвижения и инструменты для роликов. Задачи — в [ROADMAP](../ROADMAP.md): COMM-007 (промо-ролики продукта), COMM-008 (запуск и аудитория), COMM-009 (короткие смешные ролики).

## Два вида роликов

| | Короткие смешные ролики (COMM-009) | Промо продукта (COMM-007) |
|---|---|---|
| Когда | можно начинать заранее, до готовности продукта | после 100 %, редизайна и готовых сборок |
| Суть | мемные 3D-скетчи, проект упоминается косвенно: «а у меня всё само нашлось и играет» | запись экранов со всех устройств, сценарий, раскадровка |
| Где делаем | сцены и рендер — Blender, монтаж — Final Cut Pro | запись экранов, монтаж — Final Cut Pro |
| Площадки | TikTok в первую очередь, затем Reels и Shorts | сайт, сторы, все соцсети |

Позже в 3D-сцены можно вставлять реальные записи экрана Kinolune (например, на экран телевизора в сцене).

## Как это работает

1. **Сюжет.** Пишется сценарий на 15–40 секунд: крючок в первые 1–2 секунды, одна шутка или узнаваемая боль (не находится серия, «подтвердите распознавание», плеер не тянет файл), развязка, в которой всё решается само. Название проекта — в конце или в подписи, без прямой рекламы в каждом кадре.
2. **Сцена в Blender.** Сцену собирает агент через MCP для Blender (аддон «MCP for Blender»): Python-скрипты `bpy`, модели из бесплатных библиотек, свет, камера, анимация, рендер вертикального видео 1080×1920.
3. **Монтаж.** Final Cut Pro на Mac владельца, агент работает через доступ к экрану: склейка, субтитры, звук, музыка, экспорт.
4. **Публикация.** Владелец публикует сам; описание, хэштеги и метки ИИ готовит агент.

## Сервисы аддона MCP for Blender

Проверено 2026-11-20 по официальным страницам и обзорам; условия меняются — перед использованием в коммерческом ролике сверить лицензию на странице сервиса.

### Библиотеки готовых моделей

| Сервис | Бесплатно | Лицензия | Нужно ли нам |
|---|---|---|---|
| **Poly Haven** | да, без ключа | CC0 — можно всё, указывать автора не нужно | **да, включить первым**: HDRI для освещения, текстуры, модели интерьера |
| **Poly Pizza** | да, бесплатный ключ API | у каждой модели своя: CC0 или CC-BY (есть и некоммерческие — не брать) | **да**: мультяшные low-poly модели хорошо подходят для мемных скетчей |
| **Sketchfab** | да, нужен бесплатный аккаунт | Creative Commons у каждой модели своя; CC-BY требует указать автора | **да, по необходимости**: самый большой выбор (более 700 тыс. моделей) |

### Генерация моделей и миров ИИ

| Сервис | Бесплатный тариф | Коммерческое использование на бесплатном тарифе | Нужно ли нам |
|---|---|---|---|
| **Meshy** | 100 кредитов в месяц, без карты | CC BY 4.0 — можно, с указанием Meshy | **да, основной генератор** для персонажей и предметов, которых нет в библиотеках |
| **Tripo** | около 200 кредитов в месяц (~13 моделей), модели публичные | спорно: источники расходятся (CC BY 4.0 с указанием или только некоммерческое) | запасной вариант; для коммерческих роликов — только после проверки условий или на платном тарифе |
| **Tencent Hunyuan 3D** | на сайте ~20 генераций в день (по обзорам, могло измениться); открытые веса на GitHub | веса под Tencent Hunyuan Community License, не стандартная открытая лицензия | не включать без проверки лицензии |
| **Hyper3D Rodin** | генерация бесплатно, скачивание за кредиты | на бесплатном уровне не указано; коммерческая — на платных тарифах | не нужен на старте |
| **World Labs (Marble)** | 4 мира в месяц | **нет**, коммерческие права — с тарифа Pro ($35 в месяц); экспорт 3D — платно | не нужен |

**Вывод:** на старте хватит Poly Haven + Poly Pizza + Sketchfab (бесплатно) и Meshy (100 кредитов в месяц). Платные сервисы — только если ролики начнут давать заметный эффект.

### Правила для ассетов

- Для каждого ролика ведём список ассетов: откуда модель, автор, лицензия, ссылка. Авторы CC-BY перечисляются в описании ролика или в финальных титрах.
- Модели с пометками NC (некоммерческие) и ND (без изменений) не используем — ролики продвигают продукт.
- Никаких чужих брендов, логотипов и персонажей (Infuse/Firecore, Plex, Netflix, Dolby/DTS, персонажи фильмов и аниме): правило проекта и риск блокировки ролика.
- Музыка — сгенерированная или свободная с явной лицензией; трендовые звуки TikTok — только из библиотеки TikTok для коммерческого использования.

## Правила TikTok (на 2026-11)

Сводка по обзорам; перед первой публикацией сверить с [правилами сообщества TikTok](https://www.tiktok.com/community-guidelines) и справкой.

- **Метка ИИ.** Реалистичные люди и сцены, сделанные или сильно изменённые ИИ, обязательно помечаются переключателем «AI-generated content». Явная мультяшная 3D-анимация обычно не требует метки, но ставить её всё равно безопаснее. Метка сама по себе охват не снижает; неотмеченный реалистичный ИИ-контент удаляют.
- **Реклама своего продукта.** Если ролик продвигает Kinolune, включать переключатель коммерческого контента («Your brand»).
- **Аккаунт.** Отдельный аккаунт проекта, а не личный.
