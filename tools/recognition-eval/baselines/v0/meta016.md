# META-016: пороги состояний матча — замер на корпусе v0

Решение — [ADR-0101](../../../../docs/adr/0101-review-inbox.md). Распознаватель — медиатека (`pa-eval run --recognizer tmdb`, все типы), синтетический TMDB по `title-catalog.jsonl` и `tmdb-anime-catalog.jsonl`, синтетический список Anime-Lists (`catalog.py --anime-lists`) и встроенная база аниме (бандл `2026-45`), порог авто 0.92 — как в `corpus/gen/baselines.sh` (META-030). Подбор — только на train + dev; test прогнан один раз в конце, для отчёта.

## Итог

| Срез | Ветка | Precision@auto | Coverage | Recall | Тихие ошибки | Проверка | Вручную |
|---|---|---:|---:|---:|---:|---:|---:|
| train + dev | `main` | 98,79 % | 94,06 % | 92,92 % | 1,14 % (44) | 3,71 % | 2,23 % |
| train + dev | META-016 | **99,94 %** | 92,97 % | 92,92 % | **0,05 % (2)** | 4,49 % | 2,54 % |
| test | `main` (META-033, `meta033.md`) | 99,65 % | 92,56 % | 92,23 % | 0,32 % (3) | 4,10 % | 3,34 % |
| test | META-016 | 99,65 % | 92,56 % | 92,23 % | 0,32 % (3) | 4,10 % | 3,34 % |

Цель задачи — тихие ошибки ≤ 1 % на dev — выполнена: 1,14 % → 0,05 %, Recall не упал (верные авто-матчи остались авто).

## Откуда были тихие ошибки

42 из 44 — категория A4 (OVA, спешлы): папка `Fairy Tail OVA`, в TMDB только сериал `Fairy Tail` (OVA — его спешлы или вовсе нет), разметка — отдельная запись AniDB. Название файла без `OVA` совпадало с сериалом на 1,0, так что **никакой порог не помогал**: все 44 ошибки имели уверенность 1,0, а все матчи «проверьте» — 0,85 (ничья, `AMBIGUOUS`).

| Порог авто | Тихие ошибки (`main`) |
|---|---:|
| 0,90 … 0,99 | 1,14 % (44) |
| 1,00 | 1,14 % (44) |

Исправление — сигнал `lost_marker`: если в главном названии работы есть слово типа (`ova`, `oad`, `ona`, `special(s)`, `sp`, `movie`, `film`, `gekijouban`, `recap`), а в совпавшем названии кандидата его нет, оценка названия ограничена 0,85 — ниже авто, матч показывается с пометкой «проверьте». 42 матча A4 ушли в «Проверка» (A4: Precision@auto 87,00 % → 100 %, Coverage 79,75 % → 69,38 %, Recall без изменений). Оставшиеся 2 — A15 (`Shinseiki Evangelion`), уверенность 1,0.

## Нижний порог (`REVIEW`)

В синтетическом корпусе нет оценок между 0,6 и 0,85 (синтетический TMDB знает точные названия), поэтому нижний порог по корпусу не подобрать: для любого значения от 0,60 до 0,75 цифры одинаковые. `REVIEW` поднят с 0,60 до 0,70 по исследованию 03 §4.2 и ROADMAP; ниже — ручная очередь инбокса, с сохранёнными кандидатами (не «ничего», как до META-016). Подобрать его по-настоящему можно на записанной ленте реального TMDB (`--record-tmdb`, хранится локально) или по решениям пользователей в инбоксе — META-018.

Доля верных среди «Проверка» на train + dev — 33,5 % (58 из 173): пометка «проверьте» действительно отделяет сомнительные матчи.

## Как повторить

```sh
cargo build --release -p pa-eval
python3 tools/recognition-eval/corpus/gen/catalog.py --anime-lists > lists.xml
b=tools/recognition-eval/baselines/v0; c=tools/recognition-eval/corpus/v0
pa-eval run --recognizer tmdb --synthetic-tmdb $b/title-catalog.jsonl \
  --synthetic-tmdb $b/tmdb-anime-catalog.jsonl --anime-lists lists.xml \
  --anime <anime-offline-ids.jsonl> --threshold 0.92 --json out.json --md out.md \
  $c/train.jsonl $c/dev.jsonl
```

Перебор порогов — по `items[].confidence` и `items[].work` из JSON-отчёта.
