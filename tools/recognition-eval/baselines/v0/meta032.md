# META-032: реальные имена медиатеки — замер «до/после» на корпусе v0

Решение — [ADR-NNNN](../../../../docs/adr/NNNN-real-library-names.md). Корпус v0 не должен ухудшиться от новых правил (нумерованные папки, мусор сайтов, сиквел-сезоны, теги папок, короткое название папки синонимом). Оба прогона — один сервер, один бандл anime-offline-database (`2026-45`), `main` до PR против ветки PR; команды — как в `corpus/gen/baselines.sh`.

| Отчёт | Сплит | Precision@auto | Coverage | Тихие ошибки | Изменилось |
|---|---|---:|---:|---:|---|
| `parser` (title / number / season) | весь корпус | 98,13 % / 99,22 % / 100,00 % | — | — | нет |
| `tmdb` (западное подмножество, порог 0.75) | train + dev | 99,30 % | 99,30 % | 11 | нет; запросов 2 737 → 2 748 |
| `tmdb` | test | 97,12 % | 98,86 % | 10 | нет; запросов 589 → 598 |
| `scorer` (порог 0.9) | train + dev | 100,00 % | 93,60 % | 0 | нет |
| `scorer` | test | 99,26 % | 87,16 % | 6 | нет |
| медиатека + база аниме (META-030, порог 0.92, все типы) | train + dev | 98,77 % | 92,56 % | 44 | нет |
| медиатека + база аниме | test | 99,65 % | 92,56 % | 3 | нет |

«Нет» — отчёты `.md` совпадают построчно, кроме числа запросов к синтетическому TMDB (+0,4 %: синонимы «полное название с номером сиквела» и короткое название папки дают лишние поиски у нескольких работ).

Первая версия правила «короткое название папки — синоним» (без проверок на ` - ` и число после названия) роняла Coverage скорера на test 87,16 → 85,76 %: 13 файлов `Kidou Senshi Gundam 0080 - …` получали синоним `Kidou Senshi Gundam` и уходили на проверку. Правило сужено, test после этого прогнан ещё раз (второй прогон test).
