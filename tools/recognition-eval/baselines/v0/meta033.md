# META-033: названия кандидата на всех языках — замер «до/после» на корпусе v0

Решение — [ADR-NNNN](../../../../docs/adr/NNNN-other-language-titles.md). Оба прогона — один сервер, один бандл anime-offline-database (`2026-45`), `main` до PR против ветки PR; команды — как в `corpus/gen/baselines.sh`. Синтетический TMDB отвечает на новый запрос `tmdb/titles` всеми названиями записи каталога (как `/translations` и `/alternative_titles`).

Тихих ошибок не прибавилось ни в одном срезе. Рост Coverage на train + dev — в основном аниме (A2 87,78 → 97,41 %, A9 86,57 → 93,06 %), A6 и A14: синонимы и английские названия, которых нет среди русского и оригинального. Запросов больше на 4–11 %: названия на других языках запрашиваются только у слабых страниц (ничто не набрало `auto`).

Синтетический каталог знает только английское/оригинальное и русское название, а `original_title` в его ответе — английское, поэтому главный случай отчёта (японское оригинальное название, английское — только в переводах) в корпусе почти не встречается. Его проверяет регрессионный тест `core/crates/pa-catalog/tests/other_language_titles.rs`: 19 названий из отчёта владельца на синтетических ответах в форме реальных.
