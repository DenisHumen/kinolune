# META-015: модуль нумерации эпизодов — точность эпизода и ошибки по категориям

Решение — [ADR-NNNN](../../../../docs/adr/NNNN-episode-numbering-module.md). Офлайн, без запросов к TMDB, TVDB и TheXEM; порог авто 0.92 (решение владельца).

## Что сравнивается

- **Было** — код `main` до META-015: скорер META-014 (`--recognizer scorer`) и матчер медиатеки (`--recognizer tmdb`, синтетический TMDB `title-catalog.jsonl` + `tmdb-anime-catalog.jsonl` без размеров сезонов).
- **Стало, скорер** — тот же индекс плюс `--anime-lists anime-lists-synthetic.xml`: франшиза из серии, проекции AniDB → TMDB/TVDB absolute.
- **Стало, медиатека** — путь `pa-catalog` с перенумерацией (`pa_catalog::numbering`) по размерам сезонов TMDB (теперь в `tmdb-anime-catalog.jsonl`) со списком и без него.

**Список — синтетический.** `anime-lists-synthetic.xml` записан в формате Anime-Lists по правилам мейнтейнера из `titles.yaml` (`catalog.py --anime-lists`) — по тем же правилам, по которым размечены позиции TMDB и TVDB absolute корпуса. Значит, числа ниже — точность распознавания и модуля *при верных маппингах*, а не качество настоящего Anime-Lists (его в репозитории нет, лицензии нет). Разметка аниме — `draft`, сверка с TMDB/TVDB — META-025.

**Точность эпизода** — верных среди решённых авто: авто, верная работа и те же позиции в схеме. **Полнота** — верных среди размеченных (проверка и ручная очередь считаются против неё). Медиатека не выдаёт AniDB-номер (её работа — сериал TMDB, номер без записи AniDB метрика не проверяла бы), поэтому её схема AniDB — 0 по построению; done when считается по скореру, у медиатеки — схема TMDB.

```bash

```

Блок META-015 скрипта пересчитывает таблицы «стало» (`meta015-*-episodes*.md`, `meta015-library-errors*.md` против замороженного `meta013-all*.json`). Колонки «было» в этом отчёте и в `meta015-scorer-*.md` сняты один раз бинарником `main` (`pa-eval` до META-015) на тех же сплитах. Скрипт целиком пересобирает и остальные бейзлайны (`tmdb-anime-catalog.jsonl` теперь с размерами сезонов, поэтому `meta014-library-errors*.md` при перезапуске изменятся).
